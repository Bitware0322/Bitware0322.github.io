使用 PicGo+Typora+COS 搭建图床服务

发表于2026-08-30|更新于2026-08-30|博客搭建
|总字数:701|阅读时长:2分钟|浏览量:

引言

由于最近我将博客翻新了，所以想着将博客上旧文章的插图聚集到同一个图床。我旧的图床主要用的是聚合图床和Picui图床。新的图床我打算自己用腾讯COS，因为他有免费的50G空间。

工具准备

  • ﻿PicGo：一款支持多种云存储配置、快捷生成图片链接的工具。
  • Typora：一款轻量级 Markdown 编辑器，支持多种输出格式，支持将本地图片一键上传至图床。

本教程用的工具版本分别为：Picgo3.0.2、Typora1.9.4。

操作步骤

Picgo设置

在 PicGo 官网 下载和安装 PicGo 后，依次点击Setting –> General –>Choose Language，选择简体中文即可。

然后在图床列表里找到腾讯云 COS，并配置以下相关参数项：

**COS 版本：**选择 COS v5。

**设定 Secretld：**开发者拥有的项目身份识别 ID，用于身份认证，可在 API 密钥管理 页面中创建和获取。

**设定 SecretKey：**开发者拥有的项目身份密钥，可在 API 密钥管理 页面获取。

**设定 Bucket：**存储桶，COS 中用于存储数据的容器。有关存储桶的进一步说明，请参见 存储桶概述 文档。

**设定 AppId：**开发者访问 COS 服务时拥有的用户维度唯一资源标识，用以标识资源，可在 API 密钥管理 页面获取。

**设定存储区域：**存储桶所属地域信息，枚举值可参见 可用地域 文档，例如 ap-beijing、ap-hongkong、eu-frankfurt 等。

**设定存储路径：**图片存放到 COS 存储桶中的路径。

**设定自定义域名：**可选，若您为上方的存储空间配置了自定义源站域名，则可填写。相关介绍可参见 开启自定义源站域名。

**设定网址后缀：**通过在网址后缀添加 COS 数据处理参数实现图片压缩、裁剪、格式转换等操作，相关介绍可参见 图片处理。

Typora设置

  1. 打开 Typora → 文件 → 偏好设置 → 图像。
  2. 插入图片时：选「上传图片」。
  3. 上传服务：选「PicGo (app)」。
  4. PicGo 路径：指向本机 PicGo.exe（或 macOS/Linux 可执行文件）的安装位置。

配置好后，点击验证上传图片选项，验证是否配置成功。

注意！！

  • 在复制Secretld和SecretKey时，请检查前后是否有空格，不然picgo配置好后会显示上传失败！

  • 在配置好后，如果没有给存储桶配置自定义域名，在上传图片后发现没法预览图片
