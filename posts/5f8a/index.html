博客主题迁移：从 Anzhiyu 换到 Butterfly

发表于2026-08-27|更新于2026-08-27|博客搭建
|总字数:876|阅读时长:2分钟|浏览量:

引言

这个部署在Github上的博客好几个月没管了，又因为我上大二，学自动化感觉要经常记录，所以简单“翻新”一下。

为什么换主题？

Anzhiyu 是 Butterfly 的一个 fork，功能确实很多，但对我来说：

  • 大量功能我用不上（相册、追番、说说、朋友圈……），都是吃灰的代码和样式
  • 主题里塞了不少自定义的东西，维护和升级成本高
  • 我博客的主线是「折腾笔记」，想要更简洁、更专注内容

所以最终回归了 Butterfly 官方主题——功能够用、文档完善、社区大，后续升级也省心。

一、更换主题

我也是上年纪了，先前用的anzhiyu主题，这个主题虽然很丰富，但是我的博客内容很少，文章才没几篇。突然想换回简洁一点的主题 ，使其更像个记录型的博客。

1.安装

进入到hexo根目录下

2.应用主题

修改 Hexo 根目录下的 _config.yml，把主题改为 butterfly

3.安装插件

4.修改主题配置

打开/themes/butterfly/_config.yml文件，修改主题配置。

详细可参考官方文档：Butterfly 文档(三) 主题配置

总结一下修改过的配置有：

项目 改动
菜单 首页 / 标签 / 分类 / 关于 / 友人帐 / 留言板
社交链接 只留 GitHub
头像 换成新图，favicon 统一指向 /img/favicon.ico
顶图 默认顶图 + 首页图都换成新的
副标题 开启，写了两行
文章统计 开启字数 / 阅读时长
搜索 用本地搜索（local_search），配合生成 local-search.xml
评论 切换到 twikoo
灯箱 medium_zoom
侧边栏 作者卡片补了简介和 GitHub 链接，公告栏填了内容
版权 文章版权链接指向博客主页
404 开启，文案「页面走丢了，请检查地址是否正确」
结构化数据 开启，备用名「Bitware 的博客 / Bitware 折腾笔记」
字体 恢复主题默认（删掉之前自定义的字体）
注入 清空 inject.head，旧主题的遗留代码全删
懒加载 开启，站点全局、带模糊过渡

二、清除旧主题残留

这是最解压的一步。Anzhiyu / 之前的主题留下了一大堆我用不上的东西：

1.删除旧页面 / 功能

说说页、隐私协议页

相册、每日一图、世界风景、校园时光、装备、待办清单、友链朋友圈、音乐、随笔等 Anzhiyu 专属页面

2.删除旧的静态资源

删除了跟旧主题相关的source/js/、source/json/、source/css/、自定义字体 XinQuHei.ttf（3.6MB）、manifest.json`

_data 下的一堆配置文件，这里不过多赘述。

3.卸载冗余插件

  • hexo-bilibili-bangumi（追番）

  • hexo-compress（压缩）

    打开根目录下的package.json，删除hexo-compress和hexo-bilibili-bangumi两行

三、butterfly主题美化

关于主题美化我直接“借鉴”的其他大佬的，毕竟我前端方面不是很熟。

例如：hexo 博客自定义美化配置 — butterfly 主题 | 洛天的小窝

小结

换主题本质是一次「减负」——把用不上的功能清掉，回归简洁。Butterfly 配置项确实多，但对照官方文档一项项过，一天就能搞定。希望这篇对想换 Butterfly 的朋友有帮助。
